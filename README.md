## 📖 Cara Menggunakan Repository

1. **Clone Repository**

   ```bash
   git clone <repository-url>
   cd 23343032_Praktikum-Pemrograman-Jaringan
   ```

2. **Pilih Jobsheet**

   - Klik link pada tabel di atas atau navigasi ke folder yang diinginkan

3. **Install Dependencies** (jika diperlukan)

   ```bash
   cd [nama-jobsheet]
   npm install
   ```

4. **Jalankan Program**
   ```bash
   npm run dev    # Development mode (dengan auto-restart)
   npm start      # Production mode
   node app.js    # Direct execution
   ```
